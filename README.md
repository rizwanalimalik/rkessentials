# QuickList Pro | 1-Click WooCommerce Product Lister

A web application designed for fetching and extracting product data, setting custom SEO metadata, and directly pushing products into WooCommerce (WordPress) stores.

## Features
- **URL Auto Extractor & Quick Formatter**: Extracts title, pricing, images, and descriptions from supplier pages.
- **Dedicated SEO Meta Fields**: Custom fields for Search Engine Optimization:
  - Product Name for SEO (`meta_title` / Yoast & Rank Math SEO Title)
  - Details Meta Data for SEO (`meta_description` / Yoast & Rank Math SEO Description)
- **Direct WooCommerce REST API Integration**: 1-Click direct publishing to your live website (`wp-json/wc/v3/products`).
- **WooCommerce CSV Exporter**: Standard WooCommerce CSV generation for bulk import.
- **Privacy & Password Protection**: Built-in authentication barrier with session state and custom password management.
- **Luxury Dark Theme UI**: Tailored with `rk-essentials.com` branding and personalized greeting.

## Setup & Running
Open `index.html` in any modern web browser or run `start_engine.bat`.
